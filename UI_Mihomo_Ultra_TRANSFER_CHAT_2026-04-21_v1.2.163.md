## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела `Трафик` и operational-карточек делать осторожно: сначала runtime-безопасность, потом украшательства
- отдельно не ломать структуру данных от router-agent в Home Assistant через agent/handoff

## Что проверить после обновления
1. `Router -> System`: при возврате вкладки/карточки не должно быть дубля wake-up refresh.
2. `Router -> Router agent`: status refresh после возврата не должен дублироваться.
3. `Router -> Host QoS`: быстрый hide/show вкладки не должен давать лишние повторные обновления.
4. `Трафик / Пользователи`: QoS-статистика не должна дергать лишний повторный refresh при возврате вкладки.
5. `Задачи`: логика `v1.2.162` остаётся рабочей, без регрессии.
6. `Обзор`: диаграмма весов трафика остаётся живой и работает как раньше.
7. HA/export runtime и router-agent snapshot ведут себя как раньше.
8. Реальный трафик через роутер и QoS runtime не деградировали после обновления.
