## Что вошло в v1.2.171
- В `Трафик -> Устройства` добавлен явный split между `Кратким режимом` и `Расширенным режимом`.
- Краткий режим оставляет на экране основной рабочий контур: поиск, фильтры, таблицу устройств и действия, не раздувая страницу служебными карточками.
- По кнопке `Показать диагностику` можно вернуть диагностические карточки, runtime-summary и служебные подсказки; по `Скрыть диагностику` — снова убрать их из обычного рабочего контура.
- Выбранный режим сохраняется локально в браузере.
- Дополнительно добит хвост с `activeDiagnosticKey`, чтобы скрытие диагностики стабильно возвращало общий срез.
- `router-agent`, HA/export bundle shape, provider SSL checks, live traffic path и TUN этим релизом не менялись.

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки operational/UI-контуров делать осторожно: сначала runtime-безопасность, потом украшательства
- отдельно не ломать структуру данных от router-agent в Home Assistant через agent/handoff
- TUN без отдельной необходимости и отдельного тестового контура не включать

## Что проверить после обновления позже
1. `Трафик -> Устройства` по умолчанию открывается в спокойном компактном виде.
2. Кнопка `Показать диагностику` возвращает диагностические карточки и runtime-summary без поломки поиска, фильтров и действий.
3. Кнопка `Скрыть диагностику` убирает служебные блоки и сбрасывает диагностический срез.
4. После перезагрузки страницы выбранный режим сохраняется в текущем браузере.
5. HA/export runtime, provider SSL checks и реальный трафик через роутер не деградировали.
