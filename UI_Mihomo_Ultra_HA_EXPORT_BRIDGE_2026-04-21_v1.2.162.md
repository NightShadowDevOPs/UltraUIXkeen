## Что важно для HA / внешних handoff-пакетов
- В `v1.2.162` router-agent не менялся: HA/export контракт и backend telemetry path оставлены без изменений.
- Изменения релиза находятся только в UI-слое страницы `Задачи`.
- Возврат на видимую вкладку теперь мягче обрабатывает wake-up refresh для статуса `router-agent`, `Живых логов` и upstream-проверки.
- Формат данных router-agent для HA, shape JSON и export bundle этим релизом не менялись.

## Что проверять после обновления
1. `Задачи → Живые логи`: быстрый hide/show вкладки не вызывает пачку одинаковых refresh-запросов.
2. Ручное обновление логов работает как раньше.
3. Router-agent / HA snapshot продолжает работать как раньше.
4. Overview: диаграмма весов трафика продолжает работать нормально.
5. Реальный трафик через роутер не деградирует.
