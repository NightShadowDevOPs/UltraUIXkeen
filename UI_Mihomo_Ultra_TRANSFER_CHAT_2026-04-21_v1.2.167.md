## Что вошло в v1.2.167
- Глобальная проверка свежести UI-сборки (`sidebar/settings`) больше не тянет лишний fetch HTML при каждом обычном visible-resume после короткой паузы.
- Автопроверка новой сборки теперь идёт только если ещё не было успешной проверки или online bundle info реально устарел; мягкий anti-burst cooldown сохранён.
- Ручная проверка обновления UI, hard refresh, `router-agent`, HA/export shape, SSL-проверки провайдеров и реальный traffic path не менялись.
- Это safe cleanup-релиз: меньше фоновой суеты и меньше бесполезных wake-up запросов к самому роутеру.

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки operational/UI-контуров делать осторожно: сначала runtime-безопасность, потом украшательства
- отдельно не ломать структуру данных от router-agent в Home Assistant через agent/handoff

## Что проверить после обновления
1. Возврат на вкладку больше не должен без толку триггерить лишнюю автопроверку свежести UI-сборки.
2. Ручная проверка обновления UI в sidebar/settings продолжает работать штатно.
3. Hard refresh UI работает как раньше.
4. `Обзор`: диаграмма весов трафика остаётся живой и работает как раньше.
5. HA/export runtime, router-agent snapshot и реальный трафик через роутер не деградировали после обновления.
