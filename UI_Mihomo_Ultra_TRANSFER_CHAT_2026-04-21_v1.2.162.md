## Что вошло в v1.2.162
- Это восстановленный safe-патч поверх `v1.2.161`, который не дошёл отдельным архивом.
- На странице `Задачи` возврат на видимую вкладку теперь идёт через мягкий anti-burst контур для:
  - статуса `router-agent`
  - блока `Живые логи`
  - upstream-проверки
- Быстрый hide/show вкладки больше не должен подряд дёргать одинаковые refresh-запросы для этих трёх контуров.
- Обычный polling, ручное обновление и структура данных `router-agent -> HA` не менялись.

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела `Трафик` и страницы `Задачи` делать осторожно: сначала runtime-безопасность, потом украшательства
- отдельно не ломать структуру данных от router-agent в Home Assistant через agent/handoff

## Что проверить после обновления
1. `Задачи → Живые логи`: быстрый hide/show вкладки не должен вызывать пачку одинаковых wake-up refresh.

5. HA/export runtime и router-agent snapshot ведут себя как раньше.
