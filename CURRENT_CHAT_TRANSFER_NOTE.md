# UI Mihomo / Ultra — current chat transfer note

Дата: **2026-04-20**
Текущая версия UI: **v1.2.149**
Текущая версия router-agent: **0.6.32**

## Коротко по текущему состоянию
- `v1.2.148` уже разгрузил router-agent тяжёлым telemetry cache на стороне backend.
- `v1.2.149` добивает это с UI-стороны: запросы к `traffic_live`, `host_traffic_live` и `lan_hosts` теперь кратко дедуплицируются/кэшируются в клиенте.
- Overview/Traffic live-графики и host telemetry теперь используют последний стабильный снимок при кратковременном промахе telemetry, вместо резкого провала в нули.
- Реальный forwarding/runtime path и SSL-check контур провайдеров специально не трогались.

## Что обязательно помнить
- трафик через роутер не должен страдать из-за наших UI-доработок
- диаграмма с весами трафика в Обзоре должна работать нормально
- обновление UI на роутере идёт через встроенный updater интерфейса
- `router-agent` меняем только по необходимости и тогда обязательно синхронизируем версию в install/status/docs

## Что проверить после выкладки
1. Overview: диаграмма весов по трафику живая и не обнуляется при кратком telemetry hiccup.
2. Traffic: карточки хостов и общий live-блок не дёргаются/не падают в нули от единичных ошибок опроса.
3. Router runtime: трафик через роутер не просел.
4. Повторные открытия страницы/карточек не создают лишние дубль-запросы к agent endpoints.

## Следующий шаг
- если всё стабильно, идти в `v1.2.150`: аккуратно дочистить второстепенные polling-точки и посмотреть полезные cherry-pick'и из upstream без лишней нагрузки.
