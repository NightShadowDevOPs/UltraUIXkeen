# UI Mihomo / Ultra — current chat transfer note

Дата: **2026-04-20**
Текущая версия UI: **v1.2.150**
Текущая версия router-agent: **0.6.32**

## Коротко по текущему состоянию
- `v1.2.148` уже разгрузил router-agent тяжёлым telemetry cache на стороне backend.
- `v1.2.149` добавил UI-side dedupe/cache и fallback на последний стабильный live-снимок для обзорных/трафиковых графиков.
- `v1.2.150` не трогает router-agent и дальше разгружает именно второстепенный UI-контур: Host QoS и Traffic/Users теперь реже крутят summary/runtime polling, а повторные `status`, `qos_status` и `lan_hosts` reads кратко кэшируются прямо в виджетах.
- Основной live traffic contour и диаграмма весов трафика в Обзоре специально не переводились в ленивый режим.
- Реальный forwarding/runtime path и SSL-check контур провайдеров специально не трогались.

## Что обязательно помнить
- трафик через роутер не должен страдать из-за наших UI-доработок
- диаграмма с весами трафика в Обзоре должна работать нормально
- обновление UI на роутере идёт через встроенный updater интерфейса
- `router-agent` меняем только по необходимости и тогда обязательно синхронизируем версию в install/status/docs

## Что проверить после выкладки
1. Overview: диаграмма весов по трафику живая и не обнуляется при кратком telemetry hiccup.
2. Traffic → Устройства: карточка QoS устройств обновляется спокойно, без постоянного мигания загрузки.
3. Traffic → Пользователи: профили/QoS подтягиваются спокойнее на фоне, без лишней дёрготни.
4. Router runtime: трафик через роутер не просел.

## Следующий шаг
- если всё стабильно, идти в `v1.2.151`: посмотреть безопасные cherry-pick идеи из upstream и при необходимости очень выборочно дорезать только действительно вторичный polling, не трогая основной live traffic contour.
