# HA export bridge — UI Mihomo / Ultra

Дата: **2026-04-20**
Текущая версия UI: **v1.2.155**
Текущая версия router-agent: **0.6.32**

## Что важно для HA / внешних handoff-пакетов
- В `v1.2.155` router-agent не менялся: HA/export контракт и backend telemetry path оставлены без изменений.
- Изменения релиза находятся в UI-слое: во Overview → Traffic основной live polling теперь работает мягче, когда карточка трафика вне viewport.
- При видимой карточке UI возвращается к обычной частоте live-refresh, поэтому обзорная диаграмма весов не должна ощущаться «замороженной».
- secondary host-detail polling из `v1.2.154` сохранён и продолжает останавливаться вне viewport.

## Что проверять после обновления
1. Overview: диаграмма весов трафика обновляется нормально при видимой карточке.
2. Когда карточка трафика вне экрана, основной live polling идёт реже, а secondary host/QoS refresh почти не шумит.
3. После возврата карточки в viewport live-данные и host details подхватываются сразу.
4. Router runtime: реальный трафик через роутер не деградирует.

## Следующий мостовой шаг
- если `v1.2.155` стабилен на роутере, можно брать ещё один дешёвый contour или безопасный cherry-pick из upstream, но только без роста постоянного polling и без вмешательства в SSL/provider checks
