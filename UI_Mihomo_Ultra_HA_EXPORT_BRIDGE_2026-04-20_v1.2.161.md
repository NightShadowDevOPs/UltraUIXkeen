# HA export bridge — UI Mihomo / Ultra

Дата: **2026-04-20**
Текущая версия UI: **v1.2.161**
Текущая версия router-agent: **0.6.32**

## Что важно для HA / внешних handoff-пакетов
- В `v1.2.160` и `v1.2.161` router-agent не менялся: HA/export контракт и backend telemetry path оставлены без изменений.
- Изменения релиза находятся только в UI-слое страницы `Задачи`.
- Автообновление блока `Живые логи` теперь ставится на паузу, если вкладка скрыта или сам блок логов вне viewport.
- Формат данных router-agent для HA, shape JSON и export bundle этим релизом не менялись.

## Что проверять после обновления
1. `Задачи → Живые логи`: при уходе со вкладки браузера автообновление встаёт на паузу и не ломает ручное обновление.
2. `Задачи → Живые логи`: при возврате к вкладке или прокрутке к блоку логов UI делает мягкое обновление.
3. Router-agent / HA snapshot продолжает работать как раньше.
4. Overview: диаграмма весов трафика продолжает работать нормально.
5. Реальный трафик через роутер не деградирует.

## Следующий мостовой шаг
- после подтверждения `v1.2.160` + `v1.2.161` можно продолжать safe cherry-pick review из upstream и дальше чистить тяжёлые UI-хвосты без роста постоянного polling и без вмешательства в HA/export контракт
