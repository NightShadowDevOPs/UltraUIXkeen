# UI Mihomo Ultra v1.2.189 — Provider Access Links UI

Дата: 2026-05-11T12:20:00+03:00

## Суть релиза

UI-релиз для безопасного перехода провайдеров с публичных 3x-ui панелей на панели, доступные через локальный SSH-туннель на ПК.

## Что изменено

- В таблице «Прокси-провайдеры: панели управления» добавлена колонка «Ссылки доступа».
- Для каждого провайдера теперь отображаются три отдельные ссылки:
  - `Подписка` — рабочая ссылка провайдера и источник SSL-проверки.
  - `Панель · Internet` — старый внешний адрес панели.
  - `Панель · SSH` — новый локальный адрес панели через туннель, обычно `http://127.0.0.1:port/path`.
- Добавлено ручное поле для `Панель · SSH`.
- `providerPanelSshUrls` добавлен в users-db sync, чтобы значения хранились на роутере и синхронизировались между рабочими местами.
- Текущий механизм SSL-проверок не ломается: сертификаты остаются привязаны к ссылке подписки (`url` / `sslSource=subscription`).

## Что не изменено

- Не менялся Mihomo core.
- Не менялись TUN, маршрутизация, QoS, users-db формат лимитов, shapers.db.
- Не менялся router-agent runtime marker `0.6.37`.
- Не трогались Home Assistant, HA DB, штатная Home Assistant Energy, SmartLife boiler.
- Не добавлялись SSH-туннели на роутере. Адреса `127.0.0.1` предполагаются для ПК, где подняты локальные пробросы.

## Проверка после обновления UI

1. Открыть UI → раздел с провайдерами/панелями.
2. Убедиться, что строка провайдера показывает ссылки `Подписка`, `Панель · Internet`, `Панель · SSH`.
3. Вручную внести SSH-адрес вида `http://127.0.0.1:PORT/PATH`.
4. Нажать/дождаться синхронизации users-db.
5. Проверить, что ссылка сохраняется после обновления страницы.

## Комментарий по безопасности

Публичный адрес панели можно оставить временно для переходного периода. После закрытия панели с Интернета в UI должна остаться рабочая ссылка `Панель · SSH`, а SSL-проверка должна продолжать идти по подписке.
