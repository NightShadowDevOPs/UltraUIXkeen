# v1.2.193 — Provider Hosting Recurring Payments UI

## Что изменено

- В таблице провайдеров добавлен отдельный столбец `Период` для оплаты хостинга: `Разово`, `1 мес.`, `3 мес.`, `6 мес.`, `12 мес.`.
- Добавлена кнопка `Оплатил`: она переносит дату следующей оплаты на выбранный период.
- Если текущая дата уже просрочена, перенос выполняется вперёд до ближайшей будущей даты, чтобы плашка не оставалась красной после оплаты.
- Добавлена отдельная цветная плашка `Осталось ... дней`:
  - зелёная — запас больше 30 дней;
  - синяя — 8–30 дней;
  - жёлтая — 1–7 дней;
  - красная — сегодня или просрочено;
  - серая — дата не задана.
- Сроки оплаты теперь синхронизируются не только как дата, но и как период через `providerHostingPeriodMonths`.

## Что не трогали

- Mihomo core, TUN, QoS, routing, provider SSL checks — не изменялись.
- Router-agent API hotfixes v1.2.185–v1.2.188 — не менялись.
- Home Assistant, HA DB, SmartLife boiler и штатная Home Assistant Energy — не трогались.

## Проверка

После доставки UI на роутер проверить компактно:

```sh
cd /opt/etc/mihomo
set +e
/opt/bin/sh scripts/check-hosting-recurring-v1.2.193.sh
```

Ожидается `DECISION=OK`.
