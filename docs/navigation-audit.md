# Аудит навигации — v1.2.121

## Что уже разнесено по рабочим зонам
- `Router → Обзор` — короткая живая сводка по состоянию роутера
- `Router → Резервные копии` — отдельный maintenance/workspace для backup create/list/restore/delete/check/schedule
- `Traffic` — отдельная рабочая зона, внутри которой уже разделены режимы `Devices` и `Users`

## Что сделано в v1.2.121
- обзор больше не пытается быть одновременно сводкой, backup-складом и сетевой простынёй
- в обзоре оставлены быстрые карточки-переходы в `Резервные копии`, `Трафик` и `Сеть`
- `SystemCard` облегчён: live-метрики остаются видимыми сразу, а тяжёлая диагностика и проверка прошивки раскрываются только по запросу
