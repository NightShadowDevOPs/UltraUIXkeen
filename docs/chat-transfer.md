## Что вошло в v1.2.150
- UI поднят до `1.2.150`
- router-agent оставлен на `0.6.32`, backend telemetry cache не расширялся и не усложнялся
- в Host QoS и Users/QoS второстепенные auto-refresh точки сделаны заметно спокойнее: summary/runtime polling стал реже, а live telemetry оставлена отдельно и чаще только там, где она реально нужна
- добавлены короткие client-side cache окна для `status`, `qos_status` и `lan_hosts` в QoS-виджетах, чтобы повторные перерисовки и соседние refresh-циклы не дублировали одни и те же запросы
- автообновление live-графиков/статистики не отключалось: основной live path для трафика и обзорная диаграмма весов трафика не переводились в ленивый режим

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела Трафик делать осторожно: сначала runtime-безопасность, потом украшательства

## Что проверить после обновления
1. В Обзоре диаграмма весов трафика продолжает обновляться как раньше, без провалов и без ощущения, что UI «уснул».
2. В Трафике → Устройства карточка QoS устройств не мигает лишней загрузкой на фоне и не засыпает живые данные при обычном просмотре.
3. В Трафике → Пользователи профили/QoS подтягиваются спокойнее, без частого фона и без визуальной дёрготни.
4. Реальный трафик через роутер и QoS runtime не деградировали после обновления.
