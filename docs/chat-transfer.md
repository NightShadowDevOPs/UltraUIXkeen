## Что вошло в v1.2.158
- В `Задачи → Прокси-провайдеры → панели управления` строки теперь явно показывают своё состояние: **«активный»** и/или **«есть настройки / только сохранён»**.
- Удаление стало прозрачнее: если провайдер активен, кнопка удаления чистит только сохранённые UI-настройки и не убирает живую строку из runtime-списка.
- Для saved-only строк удаление полностью убирает осиротевшую запись из таблицы без визуальных хвостов.
- Добавлена краткая сводка по таблице: сколько провайдеров активных и сколько остались только в сохранённом состоянии.
- `router-agent` оставлен на `0.6.32`; live traffic / SSL runtime / provider checks не менялись.

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела Трафик делать осторожно: сначала runtime-безопасность, потом украшательства

## Что проверить после обновления
1. В `Задачи → Прокси-провайдеры → панели управления` у активных провайдеров виден бейдж **«активный»**.
2. Если у активного провайдера есть сохранённые настройки, после удаления исчезает только saved-бейдж, а сама строка остаётся.
3. Saved-only строка удаляется полностью и не оставляет хвостов в таблице.
4. Для активных провайдеров кнопка `Открыть` и SSL-индикаторы работают как раньше.
5. В Обзоре диаграмма весов трафика остаётся живой и работает как раньше.
6. Реальный трафик через роутер и QoS runtime не деградировали после обновления.
