## Что вошло в v1.2.148
- поднят UI до `1.2.148`
- поднят router-agent до `0.6.32`
- в router-agent добавлен короткий TTL cache для тяжёлых telemetry endpoints:
  - `traffic_live`
  - `host_traffic_live`
  - `qos_status`
  - `lan_hosts`
- карточка Host QoS перестала тянуть live host traffic сразу при входе на страницу; теперь тяжёлый опрос включается по demand (когда карточку реально открывают или когда страница открыта с фокусом на конкретный IP/пользователя)
- цель релиза: не ухудшить трафик/нагрузку на роутере и при этом сохранить рабочей диаграмму весов трафика в Обзоре
- HA handoff/docs синхронизированы под agent `0.6.32`

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела Трафик нужно делать осторожно: сначала runtime-безопасность, потом украшательства

## Что проверить после обновления
1. В Обзоре диаграмма весов трафика открывается и не висит пустой.
2. Раздел Трафик и карточка Host QoS открываются без заметного подвисания роутера.
3. Прокачка трафика через роутер не деградировала после установки hotfix.
4. Если открыть карточку Host QoS, live-показатели по хостам подгружаются и обновляются уже по demand.
