## Что вошло в v1.2.144
- поднят UI до `1.2.144`
- в **Host QoS** добавлены нормальные диагностические карточки: live traffic, хосты без подписи пользователя, неприменённые QoS-черновики и карточка текущего среза
- в **Traffic / Users** добавлены нормальные диагностические карточки: нет устройств, QoS без runtime-IP, пользователи близко к лимиту и активный live-трафик
- карточки сделаны **actionable**: по нажатию открывают соответствующий срез/поиск, а не просто показывают цифры
- контракт данных для **Home Assistant не менялся**: структура payload/export оставлена прежней
- обновлены transfer-файлы, snapshot памяти модели и правила workflow

## Что важно помнить
- Для этого проекта пользователь всегда ждёт: **архив релиза**, **commit message отдельно**, **команды для роутера отдельно**, **обновлённые docs**.
- В docs нужно поддерживать файл переноса в новый чат и фиксировать не только код, но и рабочие правила/формат ответов.
- Если меняется `router-agent`, нужно синхронизировать версию в `install.sh` и status API. В этом релизе agent не менялся.
- При работе с HA-интеграцией нельзя самовольно менять структуру экспортируемых данных без отдельного запроса.

## Что проверено/не проверено
- Локально проверена синтаксическая целостность изменённых Vue/locale файлов через TypeScript transpile parse.

- Значит после выкладки на рабочем окружении особенно важно проверить UI вручную.
