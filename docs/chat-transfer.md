## Что вошло в v1.2.153
- UI поднят до `1.2.153`
- router-agent оставлен на `0.6.32`, backend telemetry/runtime path не менялся
- в `RouterHealth` добавлен viewport-aware lazy polling: если карточка здоровья роутера вне viewport, её `/version` probe не долбит backend впустую
- при возврате карточки в viewport выполняется мягкий refresh, чтобы бейдж API/latency быстро подтягивался без ручного обновления
- основной live path для трафика и обзорная диаграмма весов в Обзоре специально не переводились в lazy/off-screen режим

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела Трафик делать осторожно: сначала runtime-безопасность, потом украшательства

## Что проверить после обновления
1. В Обзоре диаграмма весов трафика остаётся живой как и раньше.
2. Если карточки QoS, Router → Resources / Router agent или Router Health вне экрана, лишний фоновый polling к роутеру не идёт.
3. После возврата к карточке данные быстро освежаются без ручного тыканья Refresh.
4. Реальный трафик через роутер и QoS runtime не деградировали после обновления.
