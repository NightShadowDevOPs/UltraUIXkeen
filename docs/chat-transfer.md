## Что вошло в v1.2.149
- UI поднят до `1.2.149`
- router-agent оставлен на `0.6.32`, backend telemetry cache из `v1.2.148` не расширялся
- в UI добавлен короткоживущий dedupe/cache для запросов `traffic_live`, `host_traffic_live` и `lan_hosts`, чтобы несколько карточек не долбили один и тот же endpoint параллельно
- в `NetcrazeTrafficCard` и host live telemetry добавлен safe fallback на последний стабильный live-снимок, чтобы кратковременный срыв polling не ронял обзорные графики и трафиковые карточки в ноль
- цель релиза: ещё уменьшить UI-нагрузку на роутер, не трогая forwarding/runtime path и не ломая диаграмму весов трафика в Обзоре

## Что важно помнить дальше
- нельзя ломать автоматическую проверку SSL-сертификатов провайдеров
- обновление UI на роутере идёт через встроенный updater интерфейса, а не через `git pull`
- если меняется router-agent, нужно синхронизировать версию в `router-agent/install.sh`, status API, docs и HA handoff bundle
- любые следующие доработки раздела Трафик делать осторожно: сначала runtime-безопасность, потом украшательства

## Что проверить после обновления
1. В Обзоре диаграмма весов трафика открывается и не сваливается в нули при кратких промахах telemetry.
2. Раздел Трафик и карточки хостов не дёргаются и не обнуляются при единичных сбоях live polling.
3. Реальный трафик через роутер не деградировал после установки hotfix.
4. Повторные открытия/обновления карточек не вызывают лишнего шквала запросов к одному и тому же agent endpoint.
