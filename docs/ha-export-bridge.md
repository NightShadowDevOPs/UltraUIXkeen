# HA export bridge — UI Mihomo / Ultra

Дата: **2026-04-20**
Текущая версия UI: **v1.2.159**
Текущая версия router-agent: **0.6.32**

## Что важно для HA / внешних handoff-пакетов
- В `v1.2.159` router-agent не менялся: HA/export контракт и backend telemetry path оставлены без изменений.
- Изменения релиза находятся только в UI-слое диаграмм `Обзор`.
- Диаграммы связей/весов по источникам, клиентам и правилам теперь ставят на паузу свой внутренний snapshot refresh, когда они вне viewport или вкладка скрыта.
- Overview traffic contour, основной live runtime и связанные HA/export контракты этим релизом не менялись.

## Что проверять после обновления
1. В `Обзор` диаграммы по источникам / клиентам / правилам не продолжают фоновый refresh, когда они скрыты за пределами экрана.
2. После возврата к диаграмме она мягко обновляется и продолжает нормально работать.
3. Переключение вкладки браузера hide/show не ломает диаграммы.
4. Overview: диаграмма весов трафика продолжает работать нормально.
5. Router runtime: реальный трафик через роутер не деградирует.

## Следующий мостовой шаг
- после подтверждения `v1.2.159` можно продолжать safe cherry-pick review из upstream и дальше чистить тяжёлые UI-хвосты без роста постоянного polling и без вмешательства в SSL/provider checks
