## Что важно для HA / внешних handoff-пакетов
- В `v1.2.158` router-agent не менялся: HA/export контракт и backend telemetry path оставлены без изменений.
- Изменения релиза находятся только в UI-слое списка задач для панелей прокси-провайдеров.
- Улучшена прозрачность статуса строк: теперь лучше видно, где live runtime, а где только сохранённые UI-настройки.
- Overview traffic contour, traffic weights chart и связанные HA/export контракты этим релизом не менялись.

## Что проверять после обновления
1. В `Задачи → Прокси-провайдеры → панели управления` активные строки видны как активные.
2. Удаление на активной строке чистит только сохранённые настройки, не ломая live runtime.
3. Saved-only строки удаляются полностью и не возвращаются из локального saved-state.
4. Для активных провайдеров кнопка `Открыть` и SSL-индикаторы работают как раньше.
5. Overview: диаграмма весов трафика продолжает работать нормально.
6. Router runtime: реальный трафик через роутер не деградирует.
